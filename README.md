
# Privacy Policy – KinDreD Community

**Last Updated:** June 2026

## 1. Introduction

KinDreD Community is a Discord bot designed to provide roleplay features, role management, moderation utilities, logging systems, ticket management, and transcript generation for Discord communities.

By using the bot, server administrators and users agree to this Privacy Policy.

## 2. Information We Collect

The bot may process and store the following information when required for its functionality:

* Discord User IDs
* Discord Server (Guild) IDs
* Channel IDs
* Role IDs
* Ticket transcript data
* Moderation and logging records

The bot only accesses information necessary to provide its features.

## 3. How We Use Information

Collected information is used exclusively to:

* Manage server roles and permissions
* Operate roleplay features
* Generate moderation logs
* Create ticket transcripts
* Execute bot commands
* Maintain server management functionality

## 4. Message Content

Message content is processed only when necessary to execute commands, generate logs, or create ticket transcripts requested by server administrators.

Message content is not used for advertising, profiling, or artificial intelligence training.

## 5. Data Sharing

KinDreD Community does not sell, rent, or share user data with third parties except when required by law.

## 6. Data Retention

Data is retained only as long as necessary for the operation of the bot and its features.

Server administrators may request deletion of stored data where applicable.

## 7. Security

Reasonable measures are taken to protect stored information from unauthorized access or disclosure.

## 8. User Rights

Users and server administrators may request information about stored data or request deletion where applicable.

## 9. Changes to this Policy

This Privacy Policy may be updated periodically. Continued use of the bot after updates constitutes acceptance of the revised policy.

## 10. Contact

For questions regarding this Privacy Policy or data requests, contact the developer of KinDreD Community through Discord.
